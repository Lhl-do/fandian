# 饭点 · 按喜好和忌口推荐附近餐厅

一个本地网页应用：录入你的口味、预算、忌口和饮食约束，它给附近的店打分排序，能看到店面信息、评分、人均、评价数，能看路线、一键把目的地交给手机地图导航。

零 npm 依赖，只用 Node 18+ 的内置模块，不需要构建、不需要装包。

## 一、30 秒跑起来

推荐双击 **`server\start-web.vbs`**：不弹任何窗口，后台起服务，约 2 秒后自动帮你打开浏览器。

想看日志就用 **`启动网站.bat`**（根目录）或 `server\start-web.cmd`，会留一个黑窗口。窗口里出现下面两行就是好了：

```
饭点已启动 → http://127.0.0.1:5173
数据模式: 演示数据（未配置 amapWebKey）
```

**黑窗口版本必须一直开着，关掉 = 服务停止。** 隐藏版本（vbs）不占窗口，用 **`server\stop-web.cmd`** 停止服务。换端口：`启动网站.bat 5181` 或 `wscript server\start-web.vbs 5181`。

命令行启动（等价）：

```powershell
cd D:\大肥鱼办公区\fandian
$env:PORT='5173'
& 'C:\Users\ROG\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe' server/index.js
```

> 注意：这台机器的 `node` 不在系统 PATH 里，直接敲 `node server/index.js` 会提示“命令找不到”。启动器里用的是 node 的绝对路径，所以走启动器不用管这个。

现在默认是**演示数据模式**：20 家门店、18 种菜系、距离 310–2114 米，全部内置，不联网也能完整体验交互。

## 二、接真实高德数据（要两个 Key）

到 https://console.amap.com → 应用管理 → 我的应用 → 添加 Key，建**两个不同类型**的 Key：

| 用途 | 服务平台 | 填到 |
|---|---|---|
| 后端搜索门店、算路线 | **Web服务** | `amapWebKey` |
| 前端地图渲染 | **Web端(JS API)** + 它的安全密钥 jscode | `amapJsKey` / `amapSecurityJsCode` |

填法二选一（环境变量优先）：

**A. 环境变量**（临时）
```powershell
$env:AMAP_WEB_KEY='你的Web服务Key'
$env:AMAP_JS_KEY='你的JSAPIKey'
$env:AMAP_SECURITY_CODE='对应的jscode'
```

**B. 配置文件**（长期）：把 `config.example.json` 复制成 **`config.json`** 并填写。这个文件是私密的，别提交、别外发——「Web服务」Key 只能在服务端用，绝不能写进 `public/` 下任何文件。

改完**重启进程**才生效（配置有缓存）。确认生效看三处：启动日志变成 `数据模式: 高德实时数据`；`/api/config` 的 `hasAmapKey` 为 true；`/api/health` 的 `mode` 为 `amap`。

没配 Key 或有 Key 但调用失败时，程序不会白屏：接口照常 200，自动退回演示数据，并在页面状态条和高德接口的 `notice` 字段里写明原因（例如 `INVALID_USER_KEY`）。

## 三、手机上用（这里有个浏览器限制）

浏览器只在**安全上下文**给定位权限：`http://127.0.0.1` 算安全，但你在手机上用 `http://192.168.x.x:5173` 访问时**拿不到定位**，程序会回落到默认中心。

两个办法：
1. 在 `config.json` 里设 `defaultCenter` 成你的常用位置（形如 `{ "lng": 121.4737, "lat": 31.2304 }`），手机端就按这个点搜周边；
2. 或者自己套一层 HTTPS（自签证书在手机上通常还要额外信任，比较折腾）。

## 四、用起来

- **偏好面板**：菜系、口味多选，忌口/过敏原多选 + 自由输入，饮食约束（清真 / 素食），预算滑块，最低评分，距离半径，「只看营业中」，以及多份口味档案（给不同的人存各一套，比如「我」「家人」「加班餐」）。
- **列表**：按匹配分降序，每条显示分数、命中理由、红色忌口警告。**0 分的店不隐藏**，排到末尾并标红写明原因（例如「非清真餐厅（你需要清真）」）——让你看得见它为什么被排除。
- **深色模式**：跟随系统/浏览器的深色偏好自动切换（浅色、深色两套都做了完整的对比度校准）。
- **详情**：地址、营业时间、评分、人均、评价数、电话、照片；「看路线」画出步行/驾车路线；「高德导航」「百度导航」把目的地交给手机地图 App 做实时语音导航。
- **搜索**：输「火锅」「素食」「清真」等关键词直接过滤。

## 六、已知边界（先说清楚，免得踩坑）

1. **高德真实成功路径未验证**。开发环境没有真实 Key，只实测了「有 Key 但失败时优雅降级」（`INVALID_USER_KEY` → 自动退回演示数据）。真实 POI 数据、真实步行/驾车折线、`keywords` 参数的实际行为，需要你填了真 Key 才能确认。
2. **评价只有评分维度，没有评论正文**。高德开放平台给的是评分、人均、评论数、标签/类型；大众点评和美团没有公开接口，抓网页违反其用户协议且极易被封，所以没做。
3. **忌口判断基于店名、类型、标签关键词，不含菜品配料表**。界面上已写明这条并提示点单时向店家确认——真实地图数据里没有菜品级配料，这一条是能力边界，不是免责话术。
4. **深夜可能搜不到素食等窄口径结果**。演示数据的营业时间按真实城市节奏设置，凌晨 02:00–06:30 只有 2–5 家营业，此时再叠加「素食 + 只看营业中」可能一家都没有，这是真实情况而非 bug。
5. **页面布局未经我目视核验**。这台机器的沙箱拦截了 Chromium 的进程间通信（命名管道），无头浏览器起不来，我没法截图。已用 DOM 桩做行为级验证（渲染 19 张卡片、点击开详情、路线折线、空结果态、0 分置底标红、有 Key 无 Key 两条分支，共 28 项断言全过），但**像素级视觉效果需要你打开页面确认一次**。

本地 `127.0.0.1` 只有你自己能访问，而且关机就没了。要让别人随时打开，看 **[DEPLOY.md](DEPLOY.md)**：不需要装 git，用 Gitee 网页拖文件 + Render 免费托管，自带 https（手机定位才有权限），全程零费用。

## 八、常见问题

- **浏览器打不开 / 连接被拒**：服务没在跑。`netstat -ano | Select-String ':5173'` 有 `LISTENING` 才是真的在跑；没有就是窗口关了或进程退出了。
- **`EADDRINUSE`**：端口被占（常见于上一个窗口没关干净）。换端口 `启动网站.bat 5181`，或先查残留 `netstat -ano | Select-String ':5173'` 再按 PID 结束。
- **改了代码没变化**：浏览器缓存是关闭的（`no-cache`），但 node 进程要重启一次（配置和模块都有缓存）。
- **想看接口原始数据**：`http://127.0.0.1:5173/api/health`、`/api/config`、`/api/places?lng=121.4737&lat=31.2304&radius=3000`、`/api/route?from=121.4737,31.2304&to=121.48,31.235&mode=walking`。
